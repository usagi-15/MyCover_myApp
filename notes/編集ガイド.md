## 1. 画面の URL と、別の端末で開く方法

### URL

サーバー（`app.py`）を動かしている PC で開くとき：

| 画面 | URL |
| --- | --- |
| 机のモニター | http://127.0.0.1:5000/desk |
| 大型モニター | http://127.0.0.1:5000/display |
| スマホ用ページ（開発用） | http://127.0.0.1:5000/m/ |

**サーバーは自分の PC の中で動いているので、インターネット上には URL がありません。**
別の端末（ノートPC・タブレット・スマホ）から開くには、**同じ Wi-Fi／LAN につないだ状態で、サーバーの PC の IP アドレス**を使います。

```
http://<サーバーのPCのIPアドレス>:5000/desk
http://<サーバーのPCのIPアドレス>:5000/display
```

### 別の端末から開けるようにする手順

1. `config` フォルダに `config.local.json` というファイルを作り、次の1行を書いて保存する（すでにあるときは `"server"` の部分を足す）。

   ```json
   { "server": { "host": "0.0.0.0" } }
   ```

2. サーバーを起動し直す（2章）。黒い画面（ターミナル）に次のように出る。

   ```
   [My Cover] 同じネットワークの別の端末で開く：http://192.168.○.○:5000/desk ・ /display ・ /m/
   ```

3. 初回は Windows の「ファイアウォールでブロックされています」という画面が出るので、**「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」**。
4. 別の端末のブラウザで、表示された URL を開く。

### 開けないとき

| 原因 | 対処 |
| --- | --- |
| 別の Wi-Fi につないでいる | 両方を同じ Wi-Fi にする |
| **学内 Wi-Fi は、端末同士の通信が禁止されていることが多い** | 自宅の Wi-Fi か、スマホのテザリングに両方をつないで試す |
| ファイアウォールで「パブリック ネットワーク」扱い | Windows の設定 → ネットワークとインターネット → 使っている Wi-Fi →「プライベート ネットワーク」にする |
| `config.local.json` の書き間違い | 起動時にエラーが出る。`{` `}` や `"` を見直す |

### 注意

- `0.0.0.0` にすると、**同じネットワークにいる人なら誰でも画面を開いて操作できます**。試し終わったら `config.local.json` から `"server"` の部分を消して元に戻してください。
- **展示本番は `127.0.0.1`（元のまま）**で使います（展示PCの中の2画面だけで使うため）。
- 画面は 1920×1080 を基準に、ウィンドウに合わせて縮小表示されます。小さい画面では小さく見えますが、レイアウトは同じです。

## 2. 編集の準備

### 2-1. エディタを入れる（Visual Studio Code）

1. https://code.visualstudio.com/ から「Download for Windows」でインストール。
2. 起動して「ファイル」→「フォルダーを開く」で、プロジェクトのフォルダ（`app.py` がある場所）を開く。
3. 左のエクスプローラーからファイルを選んで編集し、**Ctrl + S で保存**。
   - 日本語化したいときは、左の拡張機能（四角のアイコン）で「Japanese Language Pack」を入れる。

### 2-2. コードの取り方：GitHub Desktop をおすすめ

ZIP でダウンロードしていると、**私（Claude）が更新した新しいコードを取り直すたびに、あなたの編集が消えてしまいます。**
GitHub Desktop を使うと、あなたの編集と私の更新を同じ場所で合わせられます。

1. https://desktop.github.com/ からインストールし、GitHub アカウントでログイン。
2. 「File」→「Clone repository」→ `usagi-15/MyCover_myApp` を選び、保存場所を決めて「Clone」。
3. 上の「Current branch」で **`claude/create-claude-docs-evzn33`** を選ぶ。
4. 「Open in Visual Studio Code」で開く。
5. **前のフォルダから `data` フォルダと `config/secrets.json` をコピー**しておく（記録と API キー）。

編集したあと：

1. GitHub Desktop に変更したファイルが一覧で出る。
2. 左下の「Summary」に何を変えたか書く（例：`D1のキャッチコピーを変更`）→「Commit to claude/create-claude-docs-evzn33」。
3. 上の「Push origin」で GitHub に送る。→ 私にも見えるようになる。

私が更新したあと：GitHub Desktop の「Fetch origin」→「Pull origin」で取り込む。

> 同じファイルの同じ場所を、あなたと私が同時に変えるとぶつかります。編集を始める前と後に、チャットで一言教えてください。

### 2-3. サーバーの起動と停止（VS Code の中で）

1. VS Code の上のメニュー「ターミナル」→「新しいターミナル」。下に黒い画面が開く。
2. 初回だけ、ライブラリを入れる：

   ```bat
   py -m pip install -r requirements.txt
   ```

3. 起動：

   ```bat
   py app.py
   ```

4. Chrome で http://127.0.0.1:5000/desk と http://127.0.0.1:5000/display を開く。
5. 停止：ターミナルをクリックして **Ctrl + C**。

（.bat ファイルは今後使わなくても大丈夫です。中身は上のコマンドと同じです。）

### 2-4. 編集を反映させる方法

| 編集したもの | 反映のしかた |
| --- | --- |
| `templates/`（HTML）・`static/`（CSS・JS）・`mobile/` | ブラウザで **Ctrl + Shift + R**（強制再読み込み） |
| `prompts/` のプロンプト・`config/ng_words.txt` | そのまま（次の生成から使われる） |
| `config/config.json`・`mycover/` の Python | サーバーを止めて（Ctrl + C）、もう一度 `py app.py` |

### 2-5. 見た目を試しながら調整する（Chrome の開発者ツール）

1. 画面で **F12** を押す（または右クリック →「検証」）。
2. 左上の矢印アイコンを押してから、変えたい文字や枠をクリック。
3. 右側の「Styles」で `font-size` や `left` などの数字をクリックして書き換えると、その場で見た目が変わる（**保存はされない**）。
4. ちょうどよい値が見つかったら、その値を CSS ファイルに書き写して保存する。

## 4. 編集のときの注意

- 保存は **UTF-8**（VS Code の標準のまま）。メモ帳で別の形式で保存すると文字化けします。
- `.json` ファイルは `,` や `"` が1つ欠けるだけで起動できなくなります。エラーが出たら、直前に変えた行を見直してください。
- 壊してしまったら、GitHub Desktop で該当ファイルを右クリック →「Discard changes」で元に戻せます。
- 変えたかったけれど場所がわからないときは、画面のスクリーンショットと「どこをどうしたいか」を送ってください。

## 5. 別の Windows PC で動かす

### 5-1. Python を入れる

- python.org の「Python install manager」（`py` コマンド）で入れた場合、最初に英語の設定画面（configuration helper）が出ることがある。
  - **「paths longer than 260 characters」**：長いファイルパスを許可するか。管理者権限がないと変更できない（学科PCでは `[WARNING]` が出て変わらないことがある）。このアプリでは不要なので、失敗しても気にしなくてよい。
  - **「Add commands directory to your PATH now? [y/N]」**：`python3.15.exe` のような名前のコマンドを使えるようにするか。このアプリは `py` コマンドを使うので **どちらでもよい**（迷ったら `y`）。
- 設定が終わったら、コマンドプロンプトで次を実行し、Python が入っているか確認する（`*` か「default」の印が付いた行があれば OK）。

  ```bat
  py list
  ```

  何も入っていないときは：

  ```bat
  py install 3.13
  ```

### 5-2. コードと、PC ごとのファイルを用意する

1. コードを取る（ZIP なら展開。**`C:\Users\<名前>\Documents\MyCover` のような短い場所**に置くと、長いパスの問題が起きにくい）。
2. 元の PC から USB メモリなどで、次をコピーする（GitHub には上がらないファイル）：

   | ファイル | 中身 | 無いと |
   | --- | --- | --- |
   | `config/secrets.json` | OpenAI・Supabase のキー | ダミー生成になり、クラウドに送られない |
   | `static/audio/B7F.mp3` | 楽曲 | 開発用のダミー音が鳴る |
   | `data` フォルダ | 記録・ギャラリー・カード | ギャラリーが空、No. が 1 から（**本番の展示PCでは必ずコピー**） |

### 5-3. 起動する

1. `start_dev.bat` をダブルクリック。
2. 青い「Windows によって PC が保護されました」が出たら、「詳細情報」→「実行」。
   - 毎回出るときは、ダウンロードした ZIP を右クリック →「プロパティ」→ 下の「許可する（ブロックの解除）」にチェック → OK のあとで展開し直す。
3. 初回はライブラリ（Flask など）のインストールに少し時間がかかる。
   - **学科の貸出PCは、追加インストールが申請制**（実装指示書 1章）。インストールでエラーになる・禁止されている場合は、学科に申請してから行う。
