## 4. 状態と音声のルール（実装）

- サーバーの状態：`desk`（画面・モーダル）、`session`（作成中の入力・試行）、`audio`、`display`、確定済みジャケット一覧。
- 音声は `audio.owner`（`desk` / `display` / なし）の画面だけが鳴らす。鳴らしている画面が再生位置をサーバーへ報告し、もう一方はそれを表示・操作する。
  - D3〜D5：desk が再生。確定時：display がサビ区間を再生 → 終了で S1。D10：display が再生し、desk の再生バーで操作。
- 確定時に No. を付与（確定順）。カード No. は Take It Home を選んだ順で別連番。
- 中止（D8「はい」）：入力・生成画像・状態を消去。

## 4b. 画像生成（フェーズ2）

- 送るプロンプト ＝ `prompts/base_prompt.txt` ＋（title_mode が `ai` のとき）`prompts/title_ai.txt` ＋「鑑賞者の言葉：」＋ 入力。
- 出力は jpeg・正方形（`openai.size`、既定 1024×1024）。モデル・品質・サイズ・圧縮率は `config` の `openai` で変更。
- **使用モデル：未確定**（仮 `gpt-image-2`）。OpenAI のドキュメントにこちらの環境から接続できなかったため、`tools/test_generate.py` で速度と仕上がりを比べて決める。openai ライブラリの記載では `gpt-image-1` は 2026/10/23 に提供終了。比較の候補は `gpt-image-2`、`gpt-image-2.5-sunburst`／`-flare`、`gpt-image-2.6-sunburst`／`-flare`（ライブラリに「対応モデル」として記載。「gpt-image-2.6」単体の名前は無い）。
- 入力チェック：
  1. 文字数（`input.max_chars`）・NGワード（`config/ng_words.txt`。全角半角・大文字小文字を区別しない部分一致）→ D3 のまま書き直しのお願い
  2. OpenAI モデレーションAPI（`omni-moderation-latest`）→ 引っかかったら D4 から D3 に戻してお願いを表示（入力は残す）
  3. 画像生成API側で安全上の理由で断られた場合も 2 と同じ扱い
- お願いの文言：「ごめんなさい、その言葉ではジャケットをつくれませんでした。別の言い方で書きなおしてみてください。」
- API障害・回線断・タイムアウト（120秒）→ D4 で「もう一度試す／言葉を変える」。
- 生成時間は成功時に毎回記録し、D4 の残り秒数は直近5回の平均から出す（記録が無いときは 30 秒）。
- タイトル：`title_mode: "ai"`（既定・決定）。`"overlay"` にすると AI への曲名の指示を外し、生成後に Pillow で固定位置（`generation.title_overlay`）に曲名を重ねる。
- API キー：環境変数 `OPENAI_API_KEY` か `config/secrets.json`（Git管理外）。`backend: "auto"` はキーがあれば OpenAI、無ければダミー。
- 予備モード（作例ジャケットで体験を続ける）はフェーズ5。

## 5. 実装上の判断（指示書に明記がなく、仮に決めたもの）

確認が取れたら更新すること。

1. **お気に入りポイント**（D10「お気に入りポイントから再生」）：定義が指示書にないため、仮に「これで生成する」を押した時点の D3 の再生位置を記録している。
2. **メニューを開ける画面**：指示書は「ホーム（待機中）でのみ」。D9（Gallery）と D2（About）にもハンバーガーがあるため（PDF p.9）、待機中の画面 D1・D2・D9 で開けるようにし、D1 以外では「Home」項目を追加した。体験中（D3〜D7）と D10 では出さない。
3. **D7a・D7b の HOME**：PDF に無いため表示しない（「終了してホームに戻る」で戻る）。
4. **サビ未設定時の S2**：0秒から `s2_fallback_seconds`（30秒）だけ再生する。
5. **D10 で曲が最後まで再生されたとき**：停止して位置を先頭に戻し、S2 のまま待つ。
6. **S1 の「新しいジャケットを目立たせる」**：確定から `highlight_new_sec`（600秒）の間、白枠と「NEW」を付け、各段に繰り返し差し込む。
7. **D1 のキービジュアル**：画像ファイルが無いため CSS のぼかしグラデーションで仮置き。
